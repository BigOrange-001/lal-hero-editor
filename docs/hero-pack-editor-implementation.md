# 英雄工坊 1.1.4 实现与验证

本版本首次以独立编辑器仓库发布。游戏源码来源与摘要见 [协议快照](game-data-snapshot.md)。当前 Windows 发行通过 Python 3.12.6、Qt/PySide 6.12.0、Pillow 13.0.0 和 PyInstaller 6.22.3 构建。

## 实现范围

保留 new／replace→patch、多英雄、多技能、结构化原生模板、拖动重排、引用守卫、玩法开关、面板基准、独立立绘、盾框与正选／反选笔、语音、工程保存、校验及多个包合并。完整操作见 [使用指南](hero-pack-editor-guide.md)，验收目标见 [需求文档](hero-pack-editor-requirements.md)。

详情页立绘与卡面是独立资源。立绘按原版常用品质画布等比适配；任意图片指派为立绘时生成独立规范化副本，不覆盖共享卡面。带框 PNG 的 lal.cardFrame 元数据决定布局边界，框外人物仍渲染。新图只提供框在下人物在上，旧工程的遮蔽配方保留。

共享模块使用游戏实际的导入／编译规则；全部原生技能可转换为结构化模板。两类新增索引映射、除零参数拒绝及范围收紧前合法包的兼容入口与已合并游戏一致。

## 本次检查

独立目录必须在没有原游戏仓库、SWF 运行包、AIR SDK、个人工程及玩家数据库的情况下启动和构建。源码检查、离屏主界面、完整模板及卡框往返、原生审查回归和冻结版检查结果记录在构建产物中；没有执行的项目不标为通过。

## 发行

构建命令为 python -B scripts/build_hero_editor.py，默认目录 build/hero-editor-release-1.1.4。发行 ZIP 包含完整运行目录、文档、许可证和 build-record.json。源码与原游戏预览素材的权利范围见仓库 README 和随包许可文本。编辑器不会替换或升级用户安装的游戏。
