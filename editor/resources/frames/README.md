# 原版品质框的透明图层

`quality-2.png` 到 `quality-6.png` 分别为白、绿、蓝、紫、橙品质。原生画布均为 **103×118**，图层只保留边框，中心与外部透明；不包含人物、标题条或推测出来的底色。按等比缩放使用，避免改变盾形轮廓。

这些文件是**原版已合成图标的公共像素重建**。原 ATF 图标已经把人物和品质框合成；没有找到可直接导出的五品质独立生产图层。因此不将重建结果称作原始独立 sprite，也没有使用 AI 绘图、套用通用盾框或重新调色来冒充原素材。

同品质使用 11／22／52／130／108 张原生尺寸一致的图标，计算每像素 RGBA 中位数后，选择距离中位数最近的真实来源像素。两张额外宽的武器图标未拉伸、未猜测对齐，直接排除。保留原版压缩纹理、高光与厚边；ATF 本身的细微压缩变化仍会存在。

`content-mask.png` 是灰度 L 蒙版：0 表示裁掉，255 表示内容区域；坐标同为完整 103×118。它由未出框低品质角色的公共原始 alpha 轮廓整理，向内收 3 像素，使内容在边框下面适当重叠，避免抗锯齿接缝。边框透明内孔使用半径 6 的圆形灰度腐蚀。`outer-silhouette.png` 保留整理前的公共轮廓。作者显式指定的前景蒙版可以让选中的透明人物部分盖到边框前方。

`source-shield-mask.png` 是原版 `UI_bg_card_2_0004` 黑盾罩的直接导出，96×116，来自 `ui_main.atf` 的 `[904,1604,96,116]`，无 trim。它作为独立原素材参考保存，**没有代替五品质厚边**，也没有以它的不同几何尺寸冒充最终剪裁轮廓。

`manifest.json` 记录每个来源图标的摘要、ATF/XML 来源及裁剪坐标、生成文件摘要和重建方法。各品质的 `quality-*-source-index.png` 为 L 模式索引图：每个像素对应该品质来源列表中的零基序号，可追溯边框 RGB 的实际原像素。`source-atlas-index.json` 原样保留先前原图集导出记录。

重新生成只需要 Python 与 Pillow，不需要运行游戏、Qt、FFDec 或安装 NumPy：

```powershell
python -B scripts/extract_hero_frames.py
```

也可以用 `--output` 指定独立目录比较结果。原图标和原始游戏素材不被改写。
